# 🛒 선착순 구매 E-Commerce
선착순 구매 프로젝트는 이커머스 서비스 내에서 선착순 구매가 진행되는 상황을 기반으로 주문을 처리하는 프로젝트입니다. 마이크로 서비스 아키텍처를 도입하여 확장성, 유연성, 유지보수 용이성을 강화할 수 있습니다.
## 🤓 개발 기간 및 인원
- 개발 기간 : 2024.08.19 ~ 2024.09.19
- 인원 : 1인

## 🔩 개발 환경
- Java 17
- Spring Boot
- MySQL
- Spring Data JPA
- Spring Security
- Spring Cloud Netflix Eureka Server,Client
- Spring Cloud Gateway
- Docker
- Kafka
- Lombok
- Google SMTP
